# Ehsan AI Trader — نسخه اولیه آزمایشی

این پروژه یک ربات تلگرام **فقط برای سیگنال‌دهی و آزمایش کاغذی (Paper Trading)** است.
هیچ سفارش واقعی ارسال نمی‌کند و کلید API معاملاتی لازم ندارد.

## امکانات
- دریافت کندل و قیمت عمومی از صرافی از طریق CCXT
- بررسی EMA20/EMA50، RSI، MACD و ATR
- ساخت سیگنال‌های احتمالی LONG/SHORT
- محاسبه حجم بر اساس ریسک و فاصله حد ضرر
- رزرو تقریبی کارمزد ورود و خروج در بودجه ریسک
- محدودیت حداکثر دو سیگنال در روز
- دفتر آزمایشی و ثبت دستی برد/باخت
- تنظیم سرمایه ۱۰۰ دلار، ریسک معمول ۱ دلار، سقف ۲ دلار و اهرم حداکثر ۲۰

## راه‌اندازی
1. Python 3.10 یا جدیدتر نصب کن.
2. در تلگرام با `@BotFather` یک ربات بساز و توکن را دریافت کن.
3. فایل `.env.example` را به `.env` تغییر نام بده.
4. توکن را در `TELEGRAM_BOT_TOKEN` قرار بده.
5. در ترمینال داخل پوشه پروژه اجرا کن:

```bash
python -m venv .venv
# ویندوز:
.venv\Scripts\activate
# مک/لینوکس:
source .venv/bin/activate

pip install -r requirements.txt
python bot.py
```

6. در تلگرام به ربات پیام `/start` بده.

## فرمان‌ها
- `/start` شروع و عضویت در اعلان‌ها
- `/scan BTC/USDT` بررسی یک نماد
- `/scanall` بررسی نمادهای تنظیم‌شده
- `/status` وضعیت دفتر آزمایشی
- `/paperwin 2` ثبت ۲ دلار سود آزمایشی
- `/paperloss 1` ثبت ۱ دلار ضرر آزمایشی

## تنظیمات مهم
در `.env`:
- `RISK_USD=1`: ریسک معمول هر سیگنال
- `MAX_RISK_USD=2`: سقف ریسک
- `MAX_SIGNALS_DAY=2`: سقف سیگنال روزانه
- `MAX_LEVERAGE=20`: اهرم محاسباتی، نه اجرای سفارش
- `FEE_RATE=0.0005`: فرض کارمزد ۰٫۰۵٪ برای هر سمت؛ با نرخ واقعی صرافی جایگزین کن.
- `TIMEFRAMES=1h,4h,1d`: تایم‌فریم‌های بررسی

## محدودیت‌ها و نکات ایمنی
- نسخه حاضر صرفاً نمونه اولیه است؛ هیچ تضمینی برای سود یا دقت سیگنال وجود ندارد.
- سیگنال‌ها بر پایه چند شاخص ساده‌اند و قبل از استفاده باید با داده تاریخی و حساب آزمایشی ارزیابی شوند.
- حجم پوزیشن با توجه به فاصله ATR و بودجه ریسک محاسبه می‌شود و به سقف ۱۰ دلار مارجین (۲۰۰ دلار پوزیشن در اهرم ۲۰) محدود است؛ بنابراین مارجین واقعی ممکن است کمتر از ۱۰ دلار باشد.
- جهت حد ضرر و هدف برای LONG و SHORT جداگانه محاسبه می‌شود. این نسخه همچنان نمونه اولیه است و باید پیش از استفاده با داده تاریخی و حساب آزمایشی ارزیابی شود.
- نرخ کارمزد، فاندینگ، اسلیپیج، حداقل اندازه سفارش و قیمت لیکوییدشدن وابسته به صرافی و قرارداد هستند.
- سقف اهرم ۲۰ فقط یک ورودی محاسباتی است؛ استفاده از اهرم بالا خطر از دست دادن سرمایه را افزایش می‌دهد.
- هیچ کلید API خصوصی یا مجوز برداشت وجه به ربات نده.
- پیش از هر تصمیم معاملاتی، خودت سیگنال را بررسی کن. این نرم‌افزار مشاوره مالی نیست.
